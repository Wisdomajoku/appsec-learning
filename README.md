# Application Security Engineering (16 Weeks)

Structured, intensive AppSec curriculum focused on vulnerability assessment, secure code review, threat modeling, and automated DevSecOps gates.

## Program Specifications
* **Cadence:** 4 hours/day, 6 days/week (~270–300 effective engineering hours)
* **Offensive/Defensive Loop:** Dynamic Exploitation (DAST) → Source Root-Cause Tracing (SAST) → Code Remediation → CI/CD Regression Gate

## Repository Architecture
* `appsec-16-week-plan.md`: Locked curriculum specification, operational rules, and deliverables.
* `appsec-progress-tracker.md`: Demonstrated competency ledger and session logs.
* `job-market-notes.md`: Real-world market calibration from active AppSec postings.
* `parking-lot.md`: Scope containment register reviewed at formal checkpoints.
* `notes/`: Technical breakdowns of vulnerability classes, security controls, and architectures.
* `labs/`: Exploit scripts, proof-of-concept payloads, and patched source code.
* `rules/`: Custom static analysis rules (Semgrep).
